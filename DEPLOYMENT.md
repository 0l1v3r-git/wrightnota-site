# GitHub Pages deployment

Repository: https://github.com/0l1v3r-git/wrightnota-site

Source: main branch, repository root `/`. `.nojekyll` disables Jekyll processing. GitHub builds and deploys the static files with its branch-based Pages service. No custom Actions workflow or package installation is needed.

1. Preview using the method in README.
2. Check both language sections of Home, Privacy and Support; review permissions and purchase wording against shipping app behavior.
3. Commit website changes and push to main.
4. Check Settings → Pages and the Pages deployment status, then open the public URLs without login.

Public URLs:

- https://0l1v3r-git.github.io/wrightnota-site/
- https://0l1v3r-git.github.io/wrightnota-site/privacy/
- https://0l1v3r-git.github.io/wrightnota-site/support/

English uses #english; Simplified Chinese uses #chinese. The base Privacy and Support URLs remain stable for store metadata.

Public support contact: wrightnota@outlook.com, shown in both languages on Privacy and Support.
