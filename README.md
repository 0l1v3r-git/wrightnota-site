# WrightNota / 现场记 public site

Minimal bilingual product, privacy and support collateral. Plain HTML and shared CSS; no build chain, JavaScript, external fonts or tracking. `.nojekyll` serves the static files directly.

## Preview

Run `python3 -m http.server 8765` in this directory, then open `http://localhost:8765/`. Check `/privacy/` and `/support/` too.

## Languages

English and Simplified Chinese share each page. Explicit links select `#english` or `#chinese`; Chinese sections use `lang="zh-Hans"`. No automatic language detection.

## Contact

Official public support email: wrightnota@outlook.com. Both languages on Privacy and Support provide clickable mailto links. No DueBak contact is reused. No website contact input remains outstanding.
